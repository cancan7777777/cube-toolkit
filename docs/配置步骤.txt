[第一步已代为完成：无需手动配置]
Supabase URL 与 Publishable key 已写入 魔方计时器/supabase-config.js，
程序打开时自动读取，任何入口都生效。
你只需做一件事：到 Supabase 控制台关闭邮箱验证
  Authentication -> Sign In / Providers -> Email -> 关闭 Confirm email
之后打开计时器自动弹出的登录框，注册即可直接登录（无需收验证邮件）。

以下为原始步骤，供参考：
请按以下顺序操作，每一步做完再进行下一步。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 1 步　建表（必做）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 左侧边栏点「SQL Editor」图标（<> 符号，或文字 SQL Editor）
2. 点右上角「New query」
3. 把桌面文件 ①_建表语句.sql 的全部内容粘贴进去
4. 点右下角「Run」，看到 Success 即成功

验证：左侧「Table Editor」里能看到 solves 表。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 2 步　确认邮箱注册已开启（重要）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

你的项目是新建的，默认可能开启了邮箱验证，
这会导致「注册后收不到验证邮件、无法登录」。

1. 左侧边栏点「Authentication」图标（人形图标）
2. 上方标签选「Sign In / Providers」（有的版本叫 Providers）
3. 找到「Email」这一项
4. 确认状态是「Enabled」
5. 如果看到「Confirm email」开关：
   - 想快速用起来 → 关掉它（注册后立即可登录）
   - 想更安全 → 保持开启，但要去邮箱里点验证链接
6. 同时确认「Email」下方的 Enable Sign ups 是开启的

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 3 步　复制两个关键信息
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 点左侧「Project Settings」（齿轮图标，最下方）
2. 进入「API」或「API Keys」页面
3. 找到 Project URL —— 应该类似：
     https://<你的项目引用ID>.supabase.co

4. 回到左侧「API Keys」页面（你截图的那一页），有两个 key：

   ✓ 填这个：Publishable key
     sb_publishable_ 开头，旁边说明写着
     「can be safely shared publicly」（可公开分享）

   ✗ 绝不填这个：Secret keys
     sb_secret_ 开头，拥有管理员权限，
     填了等于把整个数据库的控制权交出去。

   复制方法：点 key 右边的「复制」小图标。
   ⚠️ 不要手动抄写——表格里显示的是截断的（末尾有省略号），
      抄出来的 key 缺一段，必然验证失败。

   小知识：Supabase 在 2025 年把 key 格式从旧版 eyJ...（anon key）
   换成了现在的 sb_publishable_...，两种都能用，你的项目是新版。

⚠️ 安全提醒：
   anon key / publishable key 是「公开密钥」，可以放进前端代码，
   你的数据安全由上面建表时的 RLS 策略保证（只有本人能读自己的数据）。
   但 service_role / secret key 是管理员密钥，
   绝对不要填进软件里，也不要发给任何人。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 4 步　填入软件并登录
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 打开计时器 index.html
2. 点底部「设置」标签
3. 在「Supabase URL」填入第 3 步复制的 Project URL
4. 在「anon public key」填入 anon key
5. 点「保存配置」
6. 点右上角「登录」→ 切到「去注册」→ 用邮箱注册

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 5 步　验证同步成功
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 注册登录后，看顶栏右侧的状态小圆点：
   变成绿色 = 已连接账号
2. 之前在本机记录的成绩会自动上传
3. 刷新页面，成绩仍在
4. 在另一个浏览器或无痕窗口登录同一账号，成绩一样 → 同步成功

常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 保存配置后没反应？
A: 检查 URL 是否完整（开头 https://，结尾不用加 /）
   检查网络能否访问 supabase.co

Q: 点登录提示「请先在设置中配置 Supabase」？
A: 说明第 3 步没做完，或没点「保存配置」

Q: 注册后提示需要验证邮箱？
A: 回到第 2 步，把 Confirm email 关掉

Q: 数据同步很慢或失败？
A: 你的项目在东京节点，从国内访问可能不稳定。
   可在 Project Settings → Data Location 考虑改到新加坡，
   或改用国内可访问的云开发方案。

Q: 免费版项目会暂停吗？
A: 连续 7 天无活动会进入暂停状态，数据不丢，
   重新打开控制台或访问一次即可恢复。

Q: 点「保存配置」提示「连接超时」？
A: 说明 supabase.co 在当前网络下不可达（国内常见）。
   软件功能不受影响，成绩照常存在本机。
   换用手机热点等不同网络再试，或改用国内可访问的云服务。

Q: 登录时提示「请先在设置中填写 Supabase 配置」？
A: 没填配置，或填了但没点「保存配置」。
