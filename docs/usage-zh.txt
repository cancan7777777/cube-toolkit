魔方工具 · 使用说明
========================

本文件夹含两个独立工具，直接双击对应文件即可使用，无需安装任何软件。


一、CFOP公式学习
------------------------
文件：CFOP公式学习.html

双击用浏览器打开即可（推荐 Chrome / Edge）。

内容：
  · PLL 21 种情况
  · OLL 57 种情况（带官方命名）
  · F2L 41 种情况
  · 桥式 45 条（标态、M层手法、Keyhole、6E4C收尾）

特点：
  · 每条公式配一张真实的 case 图。所有图片都由公式的逆操作
    反推生成，因此图和公式严格对应，不会出现配错图的情况。
  · 支持分组浏览、搜索、只看未掌握、y 旋转切换视角。
  · 点「演示」逐帧播放这个公式；点「单步」可一步一步看。
  · 「练习模式」给图形选项让你识别 case。
  · 掌握进度保存在浏览器本地。

无需联网，可离线使用。


二、魔方计时器
------------------------
入口：index.html

重要：直接把 index.html 拖到浏览器打开也能计时，但「安装到手机」
和「云端同步」这两个功能需要通过网址访问（需本地服务器或部署到
线上）。原因见下方「如何用手机访问」。

界面说明：
  · 顶部四个标签：计时 / 统计 / 历史 / 设置
  · 打乱公式区：显示当前 scramble，可点「换一条」重新生成
  · 计时区：空格键或点击开始，再按停止
  · 锁定按钮：锁定后其他按键不会误触，但空格仍可开始/停止

键盘快捷键：
  空格      开始 / 停止
  D         罚时 +2 秒
  X         标记 DNF
  Del       删除上一把
  Esc       结束本轮
  （锁定状态下，除空格外全部失效）

赛制：
  · Bo5 / Bo10：做满 N 次取最快一次
  · 出现 DNF 时，有效成绩不足 N 次，本轮作废，需补一次
  · 自由模式：不限次数，随��练

统计口径：
  · 最快 / 最慢：分别用绿色和红色高亮标注
  · 全部平均：所有成绩直接平均
  · 去极值平均：去掉最快和最慢后取平均
  · 两种平均都会显示，可自行对比选择

其他功能：
  · 观察计时：15 秒内开始无罚时；15~17 秒判 +2；超过 17 秒判 DNF
  · 误触保护：短于 0.06 秒的成绩自动作废
  · 成绩日期精确到天，按本地时区统计
  · 每把成绩都可手动删除（鼠标移到成绩行右侧出现 ✕）
  · 支持导出 CSV
  · 支持三阶 / 二阶 / 四阶 / 单手三阶


三、如何开启账号同步（多设备查看）
------------------------
不配置也能完整使用，成绩存在本机浏览器。
配置后可在手机、电脑间同步。

准备步骤：

1. 打开 https://supabase.com 注册账号（免费）

2. 新建一个项目（Project），记下项目 URL 和 anon key

3. 在项目左侧点「SQL Editor」，新建查询并执行以下语句：

   create table solves (
     id uuid primary key default gen_random_uuid(),
     client_id uuid unique not null,
     user_id uuid references auth.users(id) on delete cascade,
     event text default '3x3',
     scramble text,
     time_ms integer,
     penalty integer default 0,
     inspection_penalty integer default 0,
     dnf boolean default false,
     session_id uuid,
     device text,
     created_at timestamptz default now()
   );

   alter table solves enable row level security;

   create policy "own rows" on solves
     for all using (auth.uid() = user_id);

4. 打开计时器的「设置」标签页，填入 URL 和 anon key，点保存

5. 点右上角「登录」注册账号

登录后，此前本机记录的成绩会自动上传。之后在任何设备登录同一
账号即可看到全部数据。

数据安全说明：RLS 策略确保每条记录只有本人可读，即使别人知道你的
用户 ID 也无法读取你的成绩。


四、如何用手机访问
------------------------
方法一：部署到免费平台（推荐）
  把「魔方计时器」文件夹整个上传到 Netlify / Vercel 等静态托管，
  获得一个 https 网址，手机浏览器打开该网址，
  再通过浏览器菜单「添加到主屏幕」，即可像 App 一样使用。

方法二：同一 WiFi 下本地访问
  在「魔方计时器」文件夹内打开命令行，执行：

      python -m http.server 8901

  然后手机浏览器访问：
      http://电脑的局域网IP:8901

  查看电脑 IP：命令行执行 ipconfig，找到 IPv4 地址。

  注意：这种方式电脑不能关机，且仅在同一 WiFi 下可用。


五、注意事项
------------------------
· 成绩保存在浏览器本地存储中。清除浏览器数据会导致记录丢失，
  重要数据建议开启账号同步，或定期导出 CSV 备份。

· 免费版 Supabase 项目若连续一周无活动会自动暂停（数据不会丢失，
  重新访问即可恢复）。

· 建议固定用同一个浏览器和同一个项目，避免数据分散。

· 【重要】为什么每次打开都要求重新配置 Supabase？
  配置存在浏览器里，且按「网址」隔离。以下入口互不相通：
    - http://127.0.0.1:8902（固定入口，推荐）
    - 聊天窗口弹出的临时预览（每次端口不同）
    - 双击打开的 file:// 页面
  请固定用「魔方计时器/启动计时器.bat」进入：
  双击后自动启动本机服务并打开固定网址，
  配置一次永久记住，成绩与登录态也保存在同一空间。

· PWA 离线功能需要通过 http:// 或 https:// 访问，直接双击打开
  文件的方式不生效。
