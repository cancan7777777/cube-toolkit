================================================================
  魔方计时器 · Cloudflare Pages 部署说明
================================================================

【要实现的效果】
  把「cloudflare部署包」里的文件发布成一个公网网址，例如
      https://cube.你的域名.com
  手机浏览器打开即可使用；注册登录后成绩与电脑互通。

【这个文件夹里有什么】
  index.html / style.css / app.js / store.js / scramble.js / sw.js
  manifest.json / icon.svg / supabase-config.js / 3 张插图
  _headers                       —— 响应头，防止“改了不生效”
  functions/sb/[[path]].js       —— Supabase 反向代理（手机连不上
                                    supabase.co 时自动启用，见文末说明）

  注意：本机用的 server.js 和 启动计时器.bat 不需要、也没有放进这个包。


================================================================
第 1 步 · 上传（二选一）
================================================================

■ 方式 A：Wrangler 命令行（推荐，能带上 functions 代理）
   在「cloudflare部署包」文件夹里打开终端（地址栏输入 cmd 回车），执行：

       npx wrangler login
       npx wrangler pages deploy . --project-name=magiccube

   - 第一次会弹出浏览器让你授权，登录你的 Cloudflare 账号即可
   - 若提示项目不存在，它会问你是否创建，选是（或先执行：
       npx wrangler pages project create magiccube --production-branch=main ）
   - 完成后会打印一个网址，形如 https://magiccube.pages.dev

■ 方式 B：网页拖拽（最简单，但不支持 functions 代理）
   1) 登录 https://dash.cloudflare.com
   2) 左侧选你的账户 → Workers & Pages
   3) 点 Create → 选 Pages → 选 Upload assets（Direct Upload）
   4) 项目名填 magiccube（小写字母/数字/短横线）
   5) 把「cloudflare部署包」里的**所有文件**拖进去（注意：
      functions 文件夹拖拽上传无效，会被忽略，不影响其他功能）
   6) 点 Deploy site，等十几秒即可

  限制：单文件最大 25 MB，单项目最多 20000 个文件 —— 我们最大的一张图
  只有 705 KB，完全没问题。


================================================================
第 2 步 · 绑定你的域名
================================================================

  1) 进入 Pages 项目 → Custom domains → Set up a domain
  2) 填一个**子域名**，例如：  cube.你的域名.com
  3) 因为你的域名已经托管在 Cloudflare，Cloudflare 会**自动创建**
     CNAME 记录并自动签发 HTTPS 证书，通常几秒到几分钟生效
  4) 浏览器打开 https://cube.你的域名.com 验证

  ⚠️ 重要提醒（避免误伤你已有的站点）
     · 请使用「子域名」（cube.xxx.com），不要用根域名（xxx.com），
       否则会把根域名原来指向的内容整个替换掉。
     · 加自定义域名之前，先到 DNS → Records 截图备份现有记录，
       尤其是有企业邮箱时（MX 记录），别动 MX。
     · 若你原来的内容占用的正是你想要的这个子域名，先按第 3 步清理。


================================================================
第 3 步 · 删除 Cloudflare 上的旧内容（按你的情况选）
================================================================

情形①：旧内容也是一个 Pages 项目
   a) 先解绑域名：进入该项目 → Custom domains → 点域名右侧三个点
      → Remove domain
   b) 再删项目：项目 → Settings → Delete project（需输入项目名确认）
   c) 最后到 DNS → Records 找到那条指向旧项目 .pages.dev 的 CNAME，
      Edit → Delete
   说明：Cloudflare 不会因为删除项目而自动删掉 DNS 记录，必须手动清。

情形②：旧内容是一个 Worker（带路由）
   a) Workers & Pages → 选中该 Worker → Settings → Delete
   b) 若它绑了路由：进入该 Worker → Settings → Triggers → 删除 Route
   c) 到 DNS → Records 删掉对应的 A / CNAME 记录

情形③：旧内容在别的服务器上，只是 DNS 指过去
   a) DNS → Records，找到该主机名的 A 或 CNAME 记录
   b) Edit → 改成 Cloudflare 自动生成的那条，或直接 Delete 后在
      Pages 项目里重新 Add custom domain（让 Cloudflare 自动建记录）
   ⚠️ 改 DNS 前务必截图备份；MX（邮件）记录不要动。

★ 如果旧内容你其实想保留，只是想让计时器用另一个子域名：
  那就完全不用删任何东西 —— 直接按第 2 步加一个新子域名即可。


================================================================
第 4 步 · 以后如何更新（改了代码重新上传）
================================================================

  · Wrangler 方式：直接在文件夹里再执行一次同样的命令
        npx wrangler pages deploy . --project-name=magiccube
    网址不变，几秒后生效。

  · 网页方式：项目 → Create new deployment → 拖入更新后的文件

  · 回滚：项目 → Deployments，点任意历史版本右侧的 ⋯ → Rollback

  更新提示：本站点已经做了两层防缓存（_headers 的 no-cache +
  内置 Service Worker 网络优先），部署后浏览器普通刷新即可拿到新版，
  不需要清缓存。若仍看到旧界面，Ctrl+F5 强刷一次。


================================================================
第 5 步 · 部署完请做这两项验证
================================================================

  1) 电脑打开你的域名 → 能正常计时、能注册/登录
  2) 进入「设置」→ 点「连接诊断」，看那一行输出：
       · 出现「代理转发 ✓ 手机请用 ……」→ 走的是 Cloudflare 代理，最好
       · 出现「直连云端 ✓ HTTP 200」   → 直连 Supabase，正常
       · 出现「直连云端 ✗」           → 该网络访问不了 supabase.co，
         此时若 functions 已部署，诊断应显示代理可用；都没通则换网络

  3) 手机打开同一网址 → 登录 → 历史成绩应能出现


================================================================
关于 functions 代理（为什么它有用）
================================================================

  你之前反馈过：手机（流量网络）无法访问 *.supabase.co，导致登录后
  看不到成绩。Cloudflare 上的这个反向代理相当于把「本机 server.js
  的局域网代理」搬到了公网：

     手机  →  你的域名/sb/...  →  Cloudflare 边缘节点  →  Supabase

  计时器会自动探测「/sb 是否可用」，可用就走代理，不可用就直连，
  所以这个文件即使没生效也不会造成故障，属于纯增益。

  唯一要留意：Cloudflare 的域名在国内部分网络下速度一般，
  如果手机上加载偏慢但功能正常，属正常现象。


================================================================
常见问题
================================================================

Q: 拖拽上传后提示 404 / 打不开？
A: 入口文件必须是根目录下的 index.html。请确认拖进去的是
   「cloudflare部署包」**里面的文件**，而不是把整个文件夹拖进去
   变成一层目录（若如此，网址要写成 /cloudflare部署包/ 才行）。

Q: 想改 Supabase 配置怎么办？
A: 编辑 supabase-config.js 里的 url / key，重新上传一次即可。

Q: 会不会产生费用？
A: Pages 免费版：无限流量、每月 500 次构建，个人使用足够。
   自定义域名、HTTPS 证书均免费。

Q: 我想绑定根域名 xxx.com（不带子域名）？
A: 可以，但要求该域名已作为 zone 托管在 Cloudflare（你的情况应该满足）。
   风险是把根域名原有内容替换掉，请先确认根域名上的旧内容可以下线。
